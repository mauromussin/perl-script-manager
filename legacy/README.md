# Script legacy

Questa directory contiene gli script Perl originali, da copiare in `legacy/scripts/` senza modifiche
dopo aver rimosso credenziali e dati sensibili.

Per ogni script annotare qui provenienza, versione e data di acquisizione (e, se utile, l'hash SHA-256).
Gli script non vanno modificati prima di aver completato l'inventario in `docs/INVENTARIO_SCRIPT.md`
e i relativi test di caratterizzazione in `t/characterization/`.
